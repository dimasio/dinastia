# Журнал решений

Решение — строка `D-NNN`: что решили и почему. Отменённое не удаляется: пометка «устарело, D-NNN».

| D-002 | TypeScript strict, Node 24 LTS, ESM                                                                                                                                                                                                           | один язык для сервера, клиента, контрактов и блоков; агенты лучше всего работают с типизированным кодом                                                                                                                                                                       |
