# Глоссарий

Единые термины для интерфейса, документации, кода и разговоров с владельцем. Новый термин — с согласия владельца. Школы термины не переименовывают (D-028).

| Термин (UI)               | Код                               | Смысл                                                       | Не говорим                              |
| ------------------------- | --------------------------------- | ----------------------------------------------------------- | --------------------------------------- |
| школа                     | `school`                          | тенант: онлайн-школа, её курсы, ученики и сотрудники        | организация, компания, аккаунт          |
| владелец школы            | `owner`                           | создатель школы, полный доступ                              | суперадмин                              |
| администратор             | `admin`                           | управляет школой, кроме удаления и тарифа                   | менеджер                                |
| преподаватель             | `teacher`                         | автор курсов, проверяет задания                             | автор, лектор, тьютор                   |
| куратор                   | `curator`                         | сопровождает поток: проверяет задания, следит за прогрессом | наставник, ментор                       |
| ученик                    | `student`                         | проходит курсы                                              | студент, слушатель, клиент              |
| сотрудник                 | `member` (не student)             | любой участник школы, кроме ученика                         | —                                       |
| участник                  | `member`                          | любой человек в школе с ролью                               | пользователь                            |
| курс                      | `course`                          | программа обучения из разделов и уроков                     | продукт, тренинг                        |
| раздел                    | `section`                         | группа уроков внутри курса                                  | модуль, глава, блок                     |
| урок                      | `lesson`                          | страница курса из блоков                                    | занятие, лекция, шаг                    |
| приглашение               | `invitation`                      | письмо со ссылкой, по которой сотрудник входит в школу      | инвайт                                  |
| блок                      | `block`                           | часть урока: текст, видео, тест, задание…                   | элемент, виджет                         |
| выноска                   | блок `callout`                    | цветная плашка в уроке: важное, внимание, совет             | callout, алерт, плашка                  |
| тест                      | блок`quiz`                        | вопросы с автоматической (или ручной) проверкой             | квиз, опрос                             |
| вопрос                    | `question`                        | элемент теста; хранится в банке вопросов курса              | —                                       |
| банк вопросов             | `questions`                       | все вопросы курса                                           | база вопросов                           |
| попытка                   | `quiz_attempt`                    | одно прохождение теста учеником                             | —                                       |
| задание, домашнее задание | блок`assignment`, `submission`    | работа ученика с ручной проверкой                           | ДЗ (только в плотных таблицах кабинета) |
| ответ на задание          | `submission`                      | то, что ученик сдал                                         | сабмит, решение                         |
| на доработку              | `needs_revision`                  | задание возвращено ученику с комментарием                   | отклонено                               |
| принято                   | `accepted`                        | задание зачтено                                             | одобрено                                |
| поток                     | `group`                           | набор учеников курса с общим стартом и кураторами           | группа, когорта                         |
| зачисление                | `enrollment`                      | доступ ученика к курсу                                      | подписка, покупка                       |
| прогресс                  | `progress_pct`, `lesson_progress` | доля пройденных уроков                                      | —                                       |
| черновик / опубликован    | `draft` / `published`             | состояние урока или курса                                   | —                                       |
| в архиве                  | `archived`                        | курс закрыт для новых учеников                              | удалён                                  |
| последовательный доступ   | `access.mode = sequential`        | урок открывается после предыдущего                          | —                                       |
| отложенный доступ         | `access.mode = drip`              | урок открывается по дате или через N дней                   | дрип                                    |
| дедлайн                   | `deadline`                        | срок сдачи урока/задания                                    | —                                       |
| сертификат                | `certificate`                     | документ о прохождении курса                                | диплом, удостоверение                   |
| кабинет школы             | область `/admin`                  | интерфейс сотрудников                                       | админка (в UI)                          |
| кабинет ученика           | область `/learn`                  | интерфейс ученика                                           | —                                       |
| оператор                  | `platform_role = operator`        | сотрудник Dinastia, поддержка школ                          | админ платформы                         |
| консоль оператора         | область `/ops`                    | интерфейс операторов SaaS                                   | суперадминка                            |

## Слова кода, которые не выходят в UI

`tenant`, `member`, `enrollment`, `block`, `registry`, `resource` — внутренние. В интерфейсе — термины из первой
колонки.
