# Глоссарий

Единые термины для интерфейса, документации, кода и разговоров с владельцем. Новый термин — с согласия владельца. Учебные центры термины не переименовывают (D-028).

**Предметная область — обучение по охране труда (D-067, 2026-11-12).** В интерфейсе, письмах, PDF, документах для людей и
release notes — только термины первой колонки. Идентификаторы кода и БД не менялись (`school`, `lesson`, `student`,
`group`, `certificate`, `assignment`), поэтому в скиллах, спеках для агентов, комментариях кода и истории задач остаются
рабочие слова «школа», «урок», «ученик», «поток», «сертификат», «домашнее задание» — это синонимы колонки «Код», не термины
интерфейса.

## Слова кода, которые не выходят в UI

`tenant`, `member`, `enrollment`, `block`, `registry`, `resource` — внутренние. В интерфейсе — термины из первой
колонки.
