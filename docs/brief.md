# Бриф: Dinastia

Итоги брифа с владельцем продукта (2026-10-24). Решения с причинами — `docs/specs/decisions.md`.

## Что строим

**SaaS-конструктор онлайн-школ — аналог skillspace.ru.** Школа (тенант) регистрируется, собирает курсы из блоков,
зачисляет учеников, кураторы проверяют домашние задания, школа видит прогресс.

Исходная идея — «переписать rnd на современный стек как инструмент разработки курсов с элементами low-code».
По итогам обсуждения: **отдельная платформа метаданных не нужна** (D-001). Low-code в продукте — для владельцев школ
(конструктор уроков, тестов, позже — лендингов и автоворонок), а для разработчиков и агентов — типизированные реестры и
генераторы. Из rnd переносим идеи и процессы, не код и не формат (`docs/specs/legacy-mapping.md`).

## Ответы

| Вопрос                   | Ответ                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| Суть                     | конструктор курсов (LMS), аналог Skillspace                                                |
| Совместимость с rnd | чистый лист, переносим идеи                                                                |
| Стек                     | TypeScript full-stack                                                                      |
| Кто пишет «low-code»     | разработчики + AI-агенты (код и описания в репозитории)                                    |
| Архитектура              | модульный монолит + реестры (без рантайм-метаданных)                                       |
| MVP                      | курсы и контент; тесты и задания; ученики и прогресс                                       |
| После MVP                | оплаты и тарифы; коммуникации (чаты, уведомления, автоворонки, CRM); геймификация и мобайл |
| Деплой                   | мультитенантный SaaS                                                                       |
| Авторизация              | логин/пароль + magic link                                                                  |
| Рынок                    | РФ, 152-ФЗ (хостинг и данные в РФ), i18n заложить                                          |
| Команда и срок           | владелец + агенты, MVP 2–3 месяца                                                          |

## Открытые вопросы (не блокируют фазу 0)

1. Название продукта и домен: рабочее имя — **Dinastia**, адреса школ `<slug>.<домен>`.
2. Видео: Kinescope (быстро, платно) или свой транскодинг в HLS (дёшево в масштабе, долго) — по умолчанию Kinescope
   за интерфейсом провайдера (D-011).
3. Облако: Yandex Cloud или Selectel — решить к фазе 5.
4. Визуальные референсы и бренд — к фазе 2 (до этого — нейтральная тема shadcn).
5. Почтовый провайдер (Unisender Go / Yandex Cloud Postbox) — к фазе 4.
