# Фаза 5. Запуск

Цель — продукт готов к первой пилотной школе: безопасность и производительность проверены, инфраструктура в РФ поднята,
наблюдаемость и бэкапы работают, юридические тексты и права субъекта ПДн на месте, оператор SaaS может поддерживать школы.
Роадмап — `docs/plan/roadmap.md` → «Фаза 5», ход — [plan.md](plan.md). Фаза ядра и платформы — по скиллу `roadmap-task`
(правка ядра в пределах пунктов разрешена); продуктовые изменения (5.5 экспорт и обезличивание, 5.6 консоль оператора) — по
`change-workflow` с карточками в [changes/](changes/).

**Демо (критерий готовности):** на стенде в РФ — регистрация школы, курс, ученик по приглашению, сертификат; оператор находит
школу и входит от имени преподавателя (видно в журнале); бэкап восстанавливается на чистую базу; e2e `tests/e2e/phase-5.spec.ts`
зелёный против стенда.
