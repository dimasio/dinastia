# 5.6а: оператор, второй фактор, создание школ в консоли, без публичной регистрации

Задача: [phase-5-launch](../task.md) · Спека: [ops.md](../../../specs/ops.md) · Шаг: готово

## 1. Запрос

Роадмап 5.6, спека `ops.md` §11 (5.6а), решения владельца 2026-11-11: школы создаёт только оператор; второй фактор операторам
обязателен. Сейчас: `users.platform_role` есть, но нигде не проверяется; школу создаёт любой вошедший (`/register`,
`schools.create`, `modules/schools/service.ts` `createSchool`); владельцу — согласия при регистрации.

## 2. Архитектура

| Слой | Что | Скилл |
| --- | --- | --- |
| Ядро auth | плагин better-auth `twoFactor` (TOTP, таблица `two_factors`, `users.two_factor_enabled`); вход по ссылке оператору не отправляется (только пароль + код) | `core-kernel`, `security-baseline` |
| Ядро orpc | `mw.operator` — сессия + `platform_role = operator`, иначе 404 `NOT_FOUND`; `mw.operator2fa` — + включён второй фактор, иначе `OPS_2FA_REQUIRED` | `core-kernel` |
| Ядро ops | модуль `kernel/ops`: `ops_audit` (глобальная, только добавление), `ops.me`, `ops.schools.create` | `core-kernel` |
| Школы | создание оператором: школа + приглашение владельца (`invitations.role = owner`, `invited_by` — null) + письмо; принятие приглашения владельцем пишет согласия с офертой и политикой Dinastia; `schools.create` и `/register` удаляются | `lms-school` |
| CLI | `pnpm ops:grant <email>` (создаст пользователя с разовым паролем, если его нет); `src/create-school.ts` — школа с владельцем для разработки и e2e | `local-env` |
| Веб | `/ops` (корень): настройка второго фактора (QR — `uqr`, MIT, уже в API), создание школы; форма входа — шаг «код из приложения»; корень без «Создать школу» | `web-screens` |

Миграции (только добавление, кроме одного ослабления): `two_factors`, `users.two_factor_enabled`, `ops_audit`,
`schools.created_by_operator_id`; `invitations.invited_by` — **NOT NULL снимается** (владельца приглашает оператор).
Контракт: `schools.create` **удаляется** (утверждено). Фикстуры тестов и e2e, создававшие школу через API/`/register`, переходят на
сервис и CLI.
