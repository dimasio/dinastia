# 5.9в: письма и сертификаты в стиле школы

Задача: [phase-5-launch](../task.md) · Спека: [branding.md](../../../specs/branding.md) (§2 сценарий 7, §5 правило 8) · Шаг: готово

## 1. Запрос

После 5.9а–б школа в своём стиле на сайте, но письма и сертификаты — нейтральные. Нужно: логотип и цвет школы в письмах и на
сертификатах.

## 2. Архитектура

| Слой | Что | Скилл |
| --- | --- | --- |
| Ядро, письма | `EmailSchool.brand` (логотип, цвет кнопки и текста на ней); `EmailLayout` — логотип вместо названия, `EmailButton` — цвет школы (через контекст макета); `deliverEmail` находит оформление по `school.id` у поставщика из реестра | `notifications`, `core-kernel` |
| Ядро, реестр | поле модуля `emailBrand` (`defineModule`) → `registerEmailBrand` — ядро не импортирует модули, оформление объявляет `schools` | `module` |
| Школы | `emailBrand`: логотип — абсолютная ссылка `https://<школа>/api/branding/logo?v=N`, кнопка — основной цвет, читаемый на белом | `lms-school` |
| Сертификаты | `CertificateData.logoSrc`, `brandColor` (по умолчанию null — старые данные валидны); логотип над названием школы, рамка и заголовок — цветом школы; в PDF — `data:` URI, в предпросмотре — подписанная ссылка | `documents` |

Шрифт школы в сертификат не переносится: в PDF встроены только PT Serif и PT Sans (D-059), спека — «если есть в наборе».
Письма платформы (вход на корне, удаление и приостановка школы) — без оформления школы.
