Задача: [phase-5-launch](../task.md) · Спека: [ops.md](../../../specs/ops.md) (§2 сценарий 6, §5 п. 4) · Шаг: готово

## 1–3. Запрос, архитектура, спека

Решения владельца 2026-11-11: только с разрешения школы, не от имени владельца, всё кроме опасного, оператору — второй фактор.
Миграция `0033_impersonation` — только добавление (`schools.support_access_until`, `sessions.impersonated_by`,
`sessions.impersonation_school_id`, `audit_log.actor_operator_id`).

## 4. Разработка

| Файл | Что |
| --- | --- |
| `kernel/auth/impersonation.ts` | плагин better-auth: `/impersonation/start` (сессия участника 1 ч с оператором и школой; сессия оператора — в подписанной cookie `ops_session`), `/impersonation/stop` (восстановление); хук: под сессией «от имени» изменения аккаунта (пароль, почта, имя) — 403 |
| `kernel/ops/impersonation.ts` | проверки (оператор + 2FA, школа `active`, доступ открыт, участник активен и не владелец), список запрещённых процедур, журнал начала/конца (школа + консоль), отзыв сессий |
| `kernel/orpc.ts` | `sessionMw` — сессия «от имени» только на поддомене своей школы (`IMPERSONATION_SCOPE`); `memberMw` — `IMPERSONATION_FORBIDDEN` и запись каждого изменения (`ops.impersonation.action`) с `actor_operator_id`; `ctx.audit` пишет оператора |
| `modules/schools/support-access.ts`, `router.ts`, `contracts/schools.ts` | `schools.supportAccess.get/set` (`schools.settings.manage`; закрытие отзывает сессии), `me.impersonation` |
| `web`: `settings/support-access.tsx`, `layout/impersonation-banner.tsx`, `ops/school-card.tsx` | «Доступ поддержки» в настройках, баннер в кабинетах с «Вернуться в консоль», «Войти как» в карточке школы |

Тесты (`ops.test.ts`, +3): без 2FA, не оператор, доступ закрыт, владелец — отказ; права на доступ поддержки; сессия только в своей
школе (не в другой школе того же человека и не на корне); запреты (приглашения, настройки, доступ поддержки, переименование через
better-auth); разрешённое изменение — в журнале с оператором; выход возвращает сессию оператора и гасит сессию «от имени»;
закрытие доступа отзывает сессию. e2e `ops.spec.ts` — открытие доступа владельцем → «Войти как» → баннер → возврат → журнал.
