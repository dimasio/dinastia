# 5.9а: тема школы — таблица оформления, токены с контрастом, CSS темы, логотип, шрифты

Задача: [phase-5-launch](../task.md) · Спека: [branding.md](../../../specs/branding.md) (§3, §5 правила 1–6) · Шаг: готово

## 1. Запрос

Роадмап 5.9, спека `branding.md` утверждена владельцем 2026-11-11: раздел «Оформление», 6 встроенных шрифтов, тема по умолчанию
от школы (ученик меняет), менять — владелец и администратор. Это изменение — основа: тема из БД применяется везде; экран — 5.9б.

## 2. Архитектура

| Слой | Что | Скилл |
| --- | --- | --- |
| Контракт | `@dinastia/contracts/branding`: схемы (цвет, шрифт, скругления, тема), расчёт токенов — контраст WCAG, OKLCH, осветление для тёмной темы, `brandingCss` | `ui-kit` |
| БД | `school_branding` (PK `school_id`, RLS), логотип и фавикон — составные FK на `files` | `db-schema` |
| API | публично по адресу школы: `/api/branding.css` (`ETag`, `no-cache`), `/api/branding/logo`, `/api/branding/favicon` (редирект на подписанную ссылку); `schools.current` и `schools.me` — `logoUrl` | `api-endpoints`, `files-media` |
| Права | `schools.branding.manage` (admin); назначения файлов `schools.logo`, `schools.favicon` (PNG/JPEG/WebP, без SVG) | `permissions` |
| Веб | `<link>` CSS темы и фавикона в `index.html` до скриптов; шрифты `@fontsource` в `packages/ui`; `ThemeProvider` берёт `--default-scheme`, класс темы — до отрисовки; `SchoolLogo` в шапках и на входе | `ui-kit`, `web-screens` |

Миграция `0034_school_branding` — только добавление. Контракт: `schools.current` и `Me.school` — новое поле `logoUrl`.
