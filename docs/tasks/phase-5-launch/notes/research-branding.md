# 5.9: как оформление школы сделано у аналогов

Источники (публичные описания, 2026-11-11):
[Teachable — Modify your school theme](https://support.teachable.com/en/articles/11682494-modify-your-school-theme),
[GetCourse — блог, оформление аккаунта](https://getcourse.ru/blog/1222168),
[Edvibe — white label для школ](https://intercom.help/edvibe/ru/articles/8069742-full-white-label-для-школ-для-новых-серверов).
По space публичной справки найти не удалось — сверить в кабинете при доступе.

| Возможность | Кто как | Берём |
| --- | --- | --- |
| Логотип, фавикон | Teachable (250×60, 32×32), Edvibe (логотип, фавикон, письма с логотипом) | берём |
| Палитра цветов | Teachable — палитра; GetCourse — темы | берём: основной и дополнительный |
| Шрифт | Teachable — выбор семейства на всю школу; GetCourse — свои шрифты | берём набор встроенных; свой файл — позже |
| Свой CSS | GetCourse — вкладка CSS в темах | не берём (ломает обновления и доступность) |
| Логотип в письмах | Edvibe | берём |
| Убрать брендинг платформы | Teachable — тариф Pro+ | позже (тарифы, фаза 6+) |
