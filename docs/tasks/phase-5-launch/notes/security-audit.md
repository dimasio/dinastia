## Проверено, замечаний нет

- **Вход и сессии**: лимиты better-auth (пароль 5/мин, ссылка 3/мин, регистрация 5/мин — в production), проверка origin/CSRF включена
  явно, cookie `HttpOnly`/`SameSite=Lax`/`Secure` по https, ссылка входа одноразовая и на 15 минут (тест).
- **HTML**: `dangerouslySetInnerHTML` — только в вёрстке PDF сертификата (`toHtml` экранирует, SVG собирает `uqr`); предпросмотр —
  `iframe sandbox` без скриптов; rich text в вебе — без `innerHTML`.
- **Файлы**: назначения с белым списком MIME и размером (SVG и HTML не принимаются), private-ссылки подписанные, скачивание — с
  `attachment`, PDF и выгрузки — 10 минут. Проверки типа по содержимому нет (сверяется заголовок, подписанный в ссылке загрузки):
  файлы отдаются с домена хранилища, не с домена приложения — **в 5.3 проверить, что домен S3 не под `*.<APP_DOMAIN>`**.
- **Исходящие запросы**: прямых `fetch` в API нет, только `ctx.http` (без приватных сетей); встраивания — белый список.
- **Ошибки**: наружу — код; стек — в лог с `requestId`.
- **ПДн в логах**: маскирование ключей (`SECRET_KEYS`, тест на каждую `pii()`-колонку), в журнал действий — без ПДн.
- **Журнал**: роли, блокировки, проверки, выгрузки, аннулирование сертификатов, включение шаблона.
