| Шаг | Что | Чем |

| а | **Изоляция школ.** Есть: RLS-покрытие (`kernel/db/rls-coverage.ts`, тест), `check:registries`. | г | **Заголовки безопасности.** Сейчас их нет: API — `secureHeaders` Hono (`nosniff`, `Referrer-Policy`, `frame-ancestors 'none'`, HSTS в production); политика CSP веба — файлом для nginx (подключится в 5.3), проверка, что приложение работает с ней (e2e на сборке) | **ядро** `app.ts`; `security-baseline` |

| е | **Ручной разбор** по чек-листу `security-baseline`: вход и сессии (лимиты, cookie, CSRF), файлы (типы, размеры, срок ссылок), SSRF (`ctx.http`), XSS (каждый `dangerouslySetInnerHTML`, iframe предпросмотра), перебор (номера сертификатов, токены приглашений), журнал действий, ПДн в логах.
