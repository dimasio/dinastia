# Фаза 4. Ученики и прогресс

Цель — школа зачисляет учеников (вручную, по приглашению, по ссылке), делит их на потоки с кураторами, ученик видит прогресс и
дедлайны, школа — аналитику, а завершивший курс получает сертификат. Роадмап — `docs/plan/roadmap.md` → «Фаза 4», ход —
[plan.md](plan.md). Продуктовая фаза: каждый пункт — изменение по `change-workflow` (карточки — [changes/](changes/)), целевую
спеку утверждает владелец. Основа готова в фазах 2–3: плеер ученика и сокращённый модуль `learning` (зачисление внутренней
функцией, `lesson_progress`, `block_progress`), результаты тестов и заданий, очередь проверки с точкой `reviewScope`.

**Демо (критерий готовности):** полный цикл от приглашения ученика до сертификата; e2e `tests/e2e/phase-4.spec.ts` зелёный.
