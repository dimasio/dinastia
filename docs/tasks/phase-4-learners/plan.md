урокам) → 4.4 (дедлайны) → 4.5 (кабинет ученика) → 4.6 (аналитика) → 4.7 (сертификаты) → 4.8 (письма). Письма, нужные раньше
(«вас записали», приглашение), делаются в своём пункте; 4.8 — оставшиеся и общий вид.
