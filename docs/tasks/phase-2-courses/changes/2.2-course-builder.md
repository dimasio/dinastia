# 2.2: конструктор курса — дерево разделов и уроков

Задача: [phase-2-courses](../task.md) · Шаг: 6 — готово

## 1. Запрос

Источник — роадмап, пункт 2.2. Сейчас (после 2.1): API дерева есть — `courses.get` отдаёт курс с разделами и уроками,
`courses.sections.create/rename/move/remove`, `courses.lessons.create/rename/move/remove`
(`apps/api/src/modules/courses/service.ts`); экрана нет — из списка «Курсы» в курс не попасть. Нужно: экран курса,
где преподаватель собирает структуру: разделы, уроки, порядок, переименование, удаление.

## 2. Архитектура

| Слой | Что меняется | Скилл |
| --- | --- | --- |
| БД, контракт, сервис | **ничего** — API из 2.1 покрывает пункт | — |
| UI | маршрут `/admin/courses/$courseId` (шаблон «Карточка», вкладка «Содержание»); переход из строки списка «Курсы» (название — ссылка); дерево разделов и уроков; оптимистичное обновление с откатом при ошибке | `web-screens`, `ui-kit`, `screen-design` |
| Зависимость | **dnd-kit** (D-010): `@dnd-kit/core` 6.3.1 + `@dnd-kit/sortable` 10.0.0 + `@dnd-kit/utilities` — в `apps/web` (MIT, стабильная линия; `@dnd-kit/react` 0.5 — ещё до 1.0) | `dependencies` |
| Строки | `courses:builder.*` | `i18n`, `ux-writing` |
| Права | экран — `courses.read`; правки (добавить, переименовать, переместить, удалить) — только с `courses.manage`, куратор видит дерево без кнопок | `permissions` |

Ядро не трогаем. Риски: перетаскивание на телефоне и с клавиатуры — поэтому у каждого элемента ещё меню
«Выше / Ниже / В раздел…» (то же API `move`). Не трогаем: редактор урока (2.3 — пункт «Открыть урок» пока ведёт на
заглушку), публикацию (2.5), настройки курса (режим доступа, срок — с плеером 2.6).

## 3. Целевая спецификация

**Задача экрана:** преподаватель при создании курса и время от времени после — собирает структуру курса: разделы,
уроки в них, порядок; быстро, без перезагрузок.

```
┌ ← Курсы   Основы акварели   [Черновик]                       [Изменить] [⋯] ┐
├ Содержание ─────────────────────────────────────────────────────────────────┤
│ ⠿ 1. Материалы и инструменты                          2 урока      [+ Урок] ⋯ │
│     ⠿ Бумага, кисти, краски                                              ⋯ │
│     ⠿ Палитра и смешивание цветов                                        ⋯ │
│ ⠿ 2. Первые работы                                    1 урок       [+ Урок] ⋯ │
│     ⠿ Заливка и растяжка                                                 ⋯ │
│                                                                            │
│ [+ Раздел]                                                                 │
│ пусто: «В курсе пока нет разделов. Добавьте первый — например, «Введение».» │
└────────────────────────────────────────────────────────────────────────────┘
⠿ — ручка перетаскивания; ⋯ — меню: Переименовать · Выше · Ниже · (урок: В раздел…) · Открыть урок · Удалить
мобильная (375): одна колонка, ручек нет — порядок только из меню ⋯; кнопки «+ Урок» под заголовком раздела
```

| Вопрос | Решение |
| --- | --- |
| роли | `courses.read` — видят дерево; `courses.manage` — ручки, «+», меню правок; куратор — только просмотр |
| состояния | загрузка — скелетон дерева; пусто — текст и «+ Раздел»; ошибка — тост с текстом кода, дерево откатывается; курса нет / нет прав — экран ошибки |
| главное действие | «+ Урок» в разделе (primary — «+ Раздел» только в пустом курсе) |
| опасные действия | удалить раздел — подтверждение «Раздел и N уроков с их содержимым будут удалены»; удалить урок — подтверждение |
| сохранение | сразу после действия (перемещение, переименование — по Enter/уходу из поля), без кнопки «Сохранить» |
| переименование | по месту: клик «Переименовать» → поле на месте названия, Enter — сохранить, Esc — отмена |
| навигация | из списка «Курсы» (название — ссылка) и обратно «← Курсы»; в адресе — id курса |
| мобильная | одна колонка, перестановка из меню ⋯, без перетаскивания |
| e2e | `course-builder`, `course-section`, `course-lesson`, `course-add-section`, `course-add-lesson`, `course-item-menu` |

Правила (`domain.md` §3 «Порядок» — из 2.1, не меняются). Новых правил предметной области нет.

### Уточнения — ответы владельца (2026-11-01)

1. **Перемещение**: перетаскивание + меню «Выше/Ниже/В раздел…» (для телефона и клавиатуры) — подходит?
2. **Переименование** — по месту (а не в диалоге) — подходит?
3. **Библиотека dnd**: `@dnd-kit/core` + `@dnd-kit/sortable` (стабильные) — подходит, или новая `@dnd-kit/react`?
4. **Вкладки карточки курса**: сейчас только «Содержание»; «Настройки» (режим доступа, срок, порог завершения) —
   с плеером (2.6), «Ученики» — фаза 4. Подходит?

Ответы: все четыре — по рекомендации (перетаскивание + меню, переименование по месту, `@dnd-kit/core` +
`@dnd-kit/sortable`, пока только вкладка «Содержание»).

Утверждено: владелец, 2026-11-01.

## 4. Разработка

| Что | Где |
| --- | --- |
| зависимость | `@dnd-kit/core` 6.3.1, `@dnd-kit/sortable` 10.0.0, `@dnd-kit/utilities` 3.2.2 (каталог, `apps/web`; MIT) |
| экран | `apps/web/src/routes/admin/courses/$courseId.tsx`, `apps/web/src/features/courses/builder/course-builder.tsx` — дерево, перетаскивание (мышь, клавиатура), меню «Переименовать / Выше / Ниже / В раздел… / Открыть урок (скоро) / Удалить», переименование по месту, оптимистичное обновление с откатом и тостом ошибки |
| список | название курса — ссылка в конструктор (ресурс стал `courses.tsx` ради JSX в колонке) |
| строки | `courses:builder.*` (формы числа для «урок/урока/уроков») |
| ядро — отступление от карточки | `@dinastia/ui` экспортирует существующий `AlertDialog` (одна строка, поведение не менялось): диалог подтверждения был только внутри ресурс-фреймворка |
| найдено снимками | текст подтверждения мигал пустым при закрытии — данные живут до конца анимации; `shoot()` ждёт окончания анимаций (иначе Radix оставлял диалог на экране) |
| тесты | e2e `tests/e2e/course-builder.spec.ts` (сборка структуры: добавить, переименовать, перенести в раздел, перетащить мышью, «Ниже», перезагрузка, удаление с числом уроков; куратор — только просмотр), снимки |

Отступление от вайрфрейма: кнопки «Изменить» в шапке нет — название курса переименовывается по месту (как разделы и
уроки), адрес — в списке «Курсы». Проверки: `pnpm check` — ok; e2e — ok. Миграций нет.
