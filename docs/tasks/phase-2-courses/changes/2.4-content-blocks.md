# 2.4: блоки контента — текст, заголовок, код, разделитель, видео и встраивание по ссылке

Задача: [phase-2-courses](../task.md) · Шаг: 6 — готово

## 1. Запрос

Источник — роадмап, пункт 2.4: `text` (Tiptap), `heading`, `image`, `video` (Kinescope/URL), `file`, `embed`,
`callout`, `divider`, `code`. Сейчас в реестре один тип — `callout` (1.3); конструктор урока (2.3) показывает любой
тип реестра без правок экрана. Белый список встраиваний — `apps/api/src/kernel/embed-allowlist.ts` (согласован
2026-10-31: YouTube, Rutube, VK Видео, Kinescope, Vimeo, Яндекс Формы, Google Формы), рендер — iframe sandbox.

Нужно: преподаватель собирает урок из привычных блоков — текст, заголовки, код, разделители, видео и встраивания.

## 2. Архитектура

| Слой | Что меняется | Скилл |
| --- | --- | --- |
| Блоки | 6 типов — по одному `pnpm gen:block <type>`: `text` (профиль `lesson`), `heading` (уровень 2–3 + строка), `code` (язык + текст), `divider` (без полей), `video` (ссылка + подпись), `embed` (ссылка + высота + подпись); категории палитры: текст — `content`, видео и встраивание — `media`, разделитель — `layout` | `lesson-blocks`, `rich-text` |
| БД | **миграции**: 6 таблиц типов `block_<type>` (+ enum языка кода и уровня заголовка) — только добавление | `db-schema` |
| Ядро (**блокер**) | белый список встраиваний нужен и схеме блока (общей для api и web), и редактору — перенести `embed-allowlist.ts` из `apps/api/src/kernel` в `packages/contracts/src/common/` без изменения списка; ядро оставит реэкспорт | `core-kernel` |
| Контракт API | без изменений (`courses.blocks.*` из 2.3 принимают любой тип реестра) | — |
| UI | редакторы и просмотры типов в `packages/blocks/src/<type>/`; видео и встраивание — `iframe` с `sandbox`, ссылка вне списка — ошибка поля «Этот сервис нельзя встроить» | `lesson-blocks`, `security-baseline` |
| Строки | `blocks:<type>.*` | `i18n` |

Не делаем (в 2.7 — вместе с загрузкой медиа): `image`, `file` и загрузку видео в Kinescope. Причина: ученику нужны
подписанные ссылки на файлы, а `toPublic` — чистая функция без доступа к хранилищу; в ядре нет шага «данные блока →
ссылки на файлы» (запрос `docs/tasks/requests/block-file-refs.md` — при утверждении). Картинки внутри текста — тоже 2.7.

## 3. Целевая спецификация

| Блок | Редактор | Ученик видит | Хранение |
| --- | --- | --- | --- |
| Текст | Tiptap, профиль `lesson`: заголовки, списки, цитата, таблица, код, ссылки | форматированный текст | `body` richText |
| Заголовок | уровень (H2, H3) + строка до 200 | заголовок раздела урока; в плеере (2.6) — пункт оглавления | `level` enum, `text` |
| Код | язык (список: обычный текст, Python, JavaScript, TypeScript, HTML, CSS, SQL, Bash, JSON) + текст до 20 000 | моноширинный блок с кнопкой «Копировать», без подсветки | `language` enum, `code` |
| Разделитель | — | горизонтальная линия | — |
| Видео | ссылка (YouTube, Rutube, VK Видео, Kinescope, Vimeo) + подпись | плеер сервиса 16:9 | `url`, `caption` |
| Встраивание | ссылка из белого списка (+ формы) + высота (200–1200 px) + подпись | iframe сервиса | `url`, `height`, `caption` |

| Вопрос | Решение |
| --- | --- |
| пусто в черновике | разрешено (как у выноски); «блок не готов к публикации» — 2.5 |
| ссылка вне списка | сохраняется черновиком нельзя: схема отклоняет, у поля — «Этот сервис нельзя встроить»; список сервисов — подсказкой под полем |
| безопасность | iframe — `sandbox="allow-scripts allow-same-origin allow-presentation allow-popups"`, `referrerpolicy="strict-origin-when-cross-origin"`, адрес встраивания строится из ссылки (не берётся как есть); заголовка CSP в проекте пока нет — не в этом пункте |
| завершение | `none` у всех (отметка просмотра урока — 2.6) |
| мобильная | просмотры — от 360px; видео и встраивание — по ширине, код — прокрутка внутри блока |
| e2e | палитра → каждый тип в уроке → «Как увидит ученик»; встраивание чужого сайта — ошибка; снимки |

Правил предметной области не прибавляется.

### Вопросы владельцу

1. **Состав 2.4**: текст, заголовок, код, разделитель, видео и встраивание по ссылке; картинку, файл и загрузку
   видео — в 2.7 вместе с загрузкой медиа (нужен механизм ядра для файлов в блоках) — подходит?
2. **Ядро**: перенести белый список встраиваний из `apps/api/src/kernel` в `packages/contracts` (список не меняется) —
   разрешаете эту правку ядра?
3. **Код**: без подсветки синтаксиса (моноширинный текст + «Копировать»; подсветка — новая зависимость, позже по
   запросу) — подходит?
4. **Видео**: только по ссылке на сервис (Kinescope — ссылкой на уже загруженное видео; загрузка из Dinastia в
   Kinescope с ключом школы — отдельная интеграция позже) — подходит?

Ответы (2026-11-01):

1. Состав — без файлов: картинка и файл — в 2.7.
2. Перенос белого списка в `packages/contracts` — разрешён.
3. Код — **с подсветкой синтаксиса**: `highlight.js` (BSD-3, релиз 2026-08; `lowlight` отклонён — последний релиз
   2024-12), ядро библиотеки + 9 языков списка, цвета — токенами темы (D-055).
4. Видео — **по ссылке и загрузкой в Kinescope**; аккаунт — **платформы** (токен в конфигурации сервера, D-011);
   загрузка — **отдельный пункт 2.4b** со своей карточкой (провайдер видео в ядре, фейк, статус обработки, вебхук).

Утверждено: владелец, 2026-11-01 (ответами на вопросы §3).

## 4. Разработка

| Что | Где |
| --- | --- |
| блоки | `packages/blocks/src/{text,heading,code,divider,video,embed}/` — `pnpm gen:block … --no-migration`, затем поля; порядок в палитре — `registry.ts` (текст, заголовок, выноска, код · видео, встраивание · разделитель), иконки — `registry.client.ts` |
| миграция | `apps/api/drizzle/0009_content_blocks.sql` — 6 таблиц `block_<type>` с RLS и каскадом на `lesson_blocks`, enum `block_heading_level`, `block_code_language`; только добавление |
| ядро (разрешено) | белый список встраиваний перенесён `apps/api/src/kernel/embed-allowlist.ts` → `packages/contracts/src/common/embed.ts` (список не менялся) + `embedSrc(url)` (адрес плеера по ссылке страницы) и `isVideoUrl`; реэкспорт в ядре не оставлен — других пользователей не было |
| подсветка | `highlight.js` 11.12.0 в `@dinastia/blocks` (D-055): ядро + 8 грамматик (`code/highlight.ts`), вывод разбирается в дерево и рисуется React-элементами — **без `innerHTML`** (скилл `security-baseline`, правило 3); цвета — классы Tailwind со светлым и тёмным вариантом |
| встраивания | `embed/frame.tsx`: iframe только по `embedSrc` из `toPublic`, `sandbox`, `referrerpolicy`, `loading="lazy"`; ошибка ссылки — у поля (`embed/url-field.tsx`) и на сервере (схема) |
| строки | `blocks:{text,heading,code,divider,video,embed}.*`; раздел палитры `content` — «Основное» (было «Текст» — совпало с названием блока) |
| тесты | `packages/contracts/src/common/embed.test.ts` (адреса плеера, отказ), `packages/blocks/src/content.test.tsx` (белый список в схемах, `toPublic`, разметка в коде остаётся текстом), API — ссылка вне списка → 400; e2e `tests/e2e/content-blocks.spec.ts` со снимками; `openNewLesson()` — в `tests/e2e/fixtures.ts` |

Проверено отдельно (разовым сценарием, не в наборе — зависит от внешнего сервиса): плеер YouTube внутри `sandbox`
загружается. На полностраничных снимках рамки пустые — `loading="lazy"` вне видимой области.

Проверки: `pnpm check` — ok; e2e — 31/31.
