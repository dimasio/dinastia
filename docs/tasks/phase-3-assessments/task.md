# Фаза 3. Тесты и задания

Цель — преподаватель собирает тест и домашнее задание, ученик проходит и сдаёт, куратор проверяет. Роадмап —
`docs/plan/roadmap.md` → «Фаза 3», ход — [plan.md](plan.md). Продуктовая фаза: каждый пункт — изменение по
`change-workflow` (карточки — [changes/](changes/)), целевую спеку утверждает владелец. Ядро вопросов (реестр типов,
хранение, ревизии, проверка — `kernel/questions`, `packages/questions`) готово в фазе 1; плеер ученика и модуль
`learning` — в фазе 2 (D-057).

**Демо (критерий готовности):** ученик проходит тест (автопроверка) и сдаёт ДЗ, куратор отправляет на доработку, ученик
пересдаёт, куратор принимает — урок завершён; e2e `tests/e2e/phase-3.spec.ts` зелёный.
