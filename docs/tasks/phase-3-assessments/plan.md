## Порядок и зависимости

3.1 (банк, теги) → 3.2 (типы вопросов; можно параллельно после 3.1) → 3.3 (блок `quiz`, попытки) → 3.6 (завершение по
`grade`, ручная проверка `open_text`) ↔ 3.4 (блок `assignment`) → 3.5 (очередь проверки). Куратор проверяет сдачи
только своих групп (`group_curators`, потоки — фаза 4): в фазе 3 до потоков куратор видит сдачи всех учеников школы или
политика уточняется в карточке 3.5.

## Открытые вопросы фазы

- Политика куратора до появления потоков (фаза 4) — в карточке 3.5.
- Ревизия вопроса при ответах (`reviseQuestion`) — «есть ли ответы» решает `assessments`; появляется с попытками (3.3).
- Плавающие e2e при 4 воркерах — нагрузка (см. план фазы 2): `workers: 2` в `playwright.config.ts` (разрешено владельцем 2026-11-08).
