## Не забыть

- Node: `source ~/.nvm/nvm.sh >/dev/null && nvm use >/dev/null && …` в каждой команде; начало — `pnpm env:check`.
- Генераторы трогал — `pnpm gen:probe`; интерфейс трогал — `pnpm e2e:shots` и посмотреть PNG (скилл visual-review);
  плавающий тест — `pnpm test:repeat`.
- Пакет правок русских доков — python-скрипт через Write (utf-8), с `assert` на каждую замену.
- `pnpm install` переписывает кавычки в `pnpm-workspace.yaml` → `pnpm exec biome check --write pnpm-workspace.yaml`.
- Длинный e2e-сценарий — `test.setTimeout(…)` с причиной; интеграционные тесты api — общий `testTimeout: 15_000`.
- Агенту в worktree: `.env` копировать из основной копии, `source ~/.nvm/nvm.sh` в песочнице может быть заблокирован —
  Node 24 через `PATH=~/.nvm/versions/node/v24.22.1/bin:$PATH`.
