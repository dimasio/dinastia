# Задача роадмапа

Роадмап — `docs/plan/roadmap.md`, архитектура — `docs/specs/architecture.md`, решения — `docs/specs/decisions.md`.
В фазах 0–1 правка ядра **разрешена** в пределах задачи фазы.

## Шаги

1. **Задача.** Нет `docs/tasks/phase-<N>-<slug>/task.md` — создай: шапка (`status: active`, `area: core|product`,
   `phase`, `created`), цель фазы, таблица задач `N.x` из роадмапа со статусами, демо-сценарий как критерий.
   Строка в `docs/tasks/README.md` — статус `active`.
2. **План пункта.** Перед пунктом `N.x` — план в `plan.md` и в чате: файлы, пакеты (с версиями — проверь актуальные
   через документацию/registry, не по памяти), что именно сверяется в скиллах. Покажи человеку, жди «ок» для
   первого пункта фазы и для пунктов с выбором библиотеки или схемы БД.
3. **Реализация.** По архитектуре. Отступление от `architecture.md` или выбор, которого там нет, — новая строка
   `D-NNN` в `decisions.md` (решение + почему) и правка `architecture.md`.
4. **Проверка.** `pnpm check` зелёный; для механизмов — тест (интеграционный для БД/RLS/прав).
5. **Сверка скиллов.** Каждый скилл, помеченный `> Статус: целевой — сверить с кодом в фазе N`, который затрагивает
   пункт: сигнатуры, пути, команды, примеры — как в коде; пометку убрать. Примеры в скилле должны компилироваться
   (возьми их из реального кода или шаблона генератора).
6. **Отметка.** Статус пункта в `task.md`, ход — в `plan.md`.
7. **Демо фазы.** e2e-сценарий демо (`tests/e2e/phase-<N>.spec.ts`) зелёный → `status: review`, покажи человеку.
   После «принято» — `done`, `closed`, разделы `architecture.md` — `current`.

## Правила

- Не выходи за таблицу фазы: всё, что «хорошо бы», — строка в `docs/tasks/requests/` или в «После MVP».
- Библиотека из `architecture.md` не подходит (заброшена, нет нужного) — остановись, предложи замену с аргументами.
- Генераторы (`tools/gen/*`) пишутся так, чтобы их вывод сразу проходил `pnpm check`; шаблоны генераторов — это и
  есть образцы в скиллах.

## Готово, когда

Все пункты фазы `done`, демо зелёный, пометки «целевой» сняты у скиллов фазы, человек принял фазу.

## Остановись и спроси, если

- пункт требует решения, которого нет в архитектуре (схема данных, библиотека, внешний сервис, стоимость);
- нужны учётные данные внешних сервисов (Kinescope, почта, облако);
- демо не проходит из-за ограничения выбранной библиотеки.
