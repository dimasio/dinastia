# Dinastia

Платформа онлайн-обучения для **учебных центров по охране труда**. Учебный центр собирает курсы из тем и блоков (текст,
видео, файлы, тесты, практические задания), зачисляет слушателей и делит их на учебные группы, кураторы проверяют задания,
слушатели получают удостоверения с номером и проверкой подлинности, центр видит прогресс и выгружает отчёты.

Оператор платформы — ООО «АИР «Горизонт»» (Академия интеллектуального развития «Горизонт»), https://airgorizont.ru.

## Что умеет

- **Учебные центры** — у каждого свой адрес (`<центр>.<домен>`), сотрудники с ролями (владелец, администратор,
  преподаватель, куратор), оформление: логотип, цвета, шрифт, тёмная тема.
- **Курсы** — разделы и темы из блоков, черновик и публикация, доступ по порядку или по расписанию, сроки сдачи.
- **Проверка знаний** — банк вопросов (7 типов), тесты с попытками и таймером, практические задания с ручной проверкой и
  доработкой.
- **Слушатели** — зачисление и приглашение по почте, учебные группы с кураторами, прогресс, аналитика, выгрузка в Excel.
- **Удостоверения** — PDF по шаблону курса, номер и QR-код, публичная проверка подлинности, аннулирование.
- **Персональные данные (152-ФЗ)** — согласия, выгрузка и обезличивание данных слушателя, удаление учебного центра, данные в РФ.
- **Консоль оператора** `/ops` — создание учебных центров, метрики, приостановка, поиск людей, вход от имени (с разрешения
  центра, со вторым фактором и журналом).

Термины интерфейса — [глоссарий](docs/specs/glossary.md) (D-067): учебный центр, тема, слушатель, учебная группа,
практическое задание, удостоверение. В коде и БД — английские идентификаторы (`school`, `lesson`, `student`…).

## Статус

Фазы 0–5 роадмапа выполнены: ядро, реестры, курсы, тесты и задания, слушатели и удостоверения, запуск (безопасность,
производительность, наблюдаемость, ПДн, консоль оператора, оформление, сборка поставки). Ждут владельца: стенд в РФ (5.3),
пилотный учебный центр (5.7), окончательные юридические тексты (сейчас — черновики с плашкой «проект»). Дальше — фаза 6
«Упаковка». Ход — [docs/tasks/README.md](docs/tasks/README.md).

## Запуск локально

Нужны Node.js 24 (`nvm install`), pnpm через corepack и Docker.

```bash
nvm use
pnpm install
cp .env.example .env     # значения по умолчанию подходят для docker compose
pnpm env:up              # PostgreSQL 18, SeaweedFS (S3), Mailpit
pnpm db:migrate
pnpm db:seed             # демо-данные; плюс pnpm db:seed:trud — учебный центр по охране труда
pnpm dev                 # API :3000 + воркер задач + сайт :5173
pnpm env:check           # всё ли готово, с командами исправления
```

| Что | Адрес | Вход |
| --- | --- | --- |
| демо-центр | http://demo.dinastia.localhost:5173 | `owner@demo.local`, `teacher@demo.local`, `student1@demo.local` — пароль `demo12345` |
| центр по охране труда | http://trud.dinastia.localhost:5173 | `owner@trud.local` и др. — пароль `demo12345` (список печатает `pnpm db:seed:trud`) |
| консоль оператора | http://dinastia.localhost:5173/ops | `ops@demo.local` / `demo12345` + код из приложения-аутентификатора |
| письма (Mailpit) | http://localhost:8025 | — |

Подробнее — скилл `local-env` (`docs/skills/platform/local-env/SKILL.md`).
