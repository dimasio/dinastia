# Оферта на использование платформы Dinastia

Редакция: проект (draft-2026-10).

## 1. Общие положения

1. Настоящая оферта — предложение оператора платформы Dinastia (далее — Платформа) заключить договор на использование
   сервиса для создания и проведения онлайн-обучения (далее — Сервис).
2. Акцептом оферты считается регистрация школы на Платформе.

## 2. Предмет

1. Платформа предоставляет школе доступ к Сервису: создание курсов, приём учеников, проверку заданий, выдачу сертификатов.
2. Школа самостоятельно определяет содержание курсов и отвечает за него.

## 3. Персональные данные

1. Школа — оператор персональных данных своих учеников и сотрудников. Платформа обрабатывает их по поручению школы и
   только для работы Сервиса.
2. Данные хранятся на серверах в Российской Федерации.
3. Школа может выгрузить и удалить данные ученика, а также удалить школу со всеми данными.
